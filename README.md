## 🚀 Características Técnicas de la Página

- **HTML5 & CSS3 Puramiente adaptativo:** Compatible con computadoras, tablets y teléfonos móviles.
- **Efectos Neón & RGB Animados:** Bordes, títulos e iluminación dinámica en bucle mediante animaciones CSS keyframes.
- **Tipografía Gamer:** Integración con Google Fonts (*Press Start 2P* y *Chakra Petch*).

## 🛠️ Tecnologías Analizadas en el Proyecto

- **Supabase:** Backend as a Service (BaaS) de código abierto.
- **PostgreSQL:** Motor de base de datos relacional.
- **Row Level Security (RLS):** Control de permisos a nivel de filas.
- **APIs REST y SDK JavaScript:** Conexión asíncrona entre cliente y servidor.
